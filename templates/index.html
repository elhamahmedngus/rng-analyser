A vault is only as strong as the number that unlocks it.

RNG Analyser encrypts messages with real AES-256-GCM. Every key and nonce it uses comes from a random number generator — and this system lets you watch what happens when that generator is weak instead of strong.

Encrypt a message Try the key generator

Secure mode

Keys and nonces are generated with Python's secrets module — a cryptographically secure RNG. There is no shortcut from any public value back to the key.

Insecure mode (for the demo)

Keys are derived from a Linear Congruential Generator, the same class of weak RNG behind several real historical key-generation failures. Encrypt a message in this mode, then open the Attack Lab to see it broken using nothing but a single leaked value.

Why this matters

AES-256-GCM is not broken by trying every key — the keyspace is far too large. Attackers who succeed almost never break the cipher itself; they find a shortcut to the key. A predictable RNG is one of the most common shortcuts in real software, which is why key generation deserves as much scrutiny as the encryption algorithm wrapped around it.
